# Key of correct answers for dataset of admission test to medical school

The `dataMedicalkey` is a vector of factors representing correct answers
of `dataMedicaltest` dataset.

## Usage

``` r
dataMedicalkey
```

## Format

A vector with 100 values representing correct answers to items of
`dataMedicaltest` dataset. For more details see
[`dataMedicaltest()`](dataMedicaltest.md).

## Source

Stuka, C., Vejrazka, M., Martinkova, P., Komenda, M., & Stepanek, L.
(2016). The use of test and item analysis for improvement of tests.
Workshop held at conference MEFANET, 2016, Brno, Czech Republic.
